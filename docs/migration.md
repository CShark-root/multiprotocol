# Переезд на VPS

Сервер: Ubuntu 22.04, 1 vCPU, 2 ГБ RAM. На нём уже работают Amnezia (Docker) и 3x-ui с VLESS на 443. Amnezia не трогаем вообще. 3x-ui убираем в самом конце, когда наше заработало.

## 0. Перед началом

1. **Снапшот VPS у хостера.** Это главная страховка: откат за минуту.
2. В 3x-ui запишите или сохраните параметры текущего VLESS, на случай отката.
3. С VM: «Настройки → Резервная копия → Скачать», если хотите перенести пользователей и настройки. Иначе начнём с чистой панели.

## 1. Посмотреть сервер (ничего не меняет)

```bash
curl -fsSL https://raw.githubusercontent.com/CShark-root/multiprotocol/main/scripts/vps-check.sh | sudo bash
```

Что смотрим в выводе:
- кто держит 443 (`x-ui` / `xray` 3x-ui) и какие порты заняты Amnezia (`docker-proxy`);
- есть ли файрвол (ufw или правила iptables): тогда порты панели и подключений придётся открыть;
- память: сколько остаётся после контейнеров Amnezia.

## 2. Установка

```bash
curl -fsSL https://raw.githubusercontent.com/CShark-root/multiprotocol/main/install.sh | sudo bash
```

Установщик:
- ставит панель и ядра (Xray, Hysteria2, sing-box);
- ставит службы `panel`, `panel-amnezia` (только чтение Docker) и `panel-update` (кнопка «Обновить»);
- включает BBR (файл `/etc/sysctl.d/90-panel.conf`).

Docker, контейнеры Amnezia и 3x-ui он не трогает. В конце печатает адрес панели вида `https://IP:ПОРТ/<секрет>/` и отпечаток сертификата.

Если на сервере включён ufw, откройте порт панели: `sudo ufw allow ПОРТ/tcp`. Порты подключений открывайте так же, по мере их создания.

## 3. Первый вход

Откройте адрес из вывода установщика. Браузер предупредит о самоподписанном сертификате: сверьте отпечаток. Создайте администратора, затем сразу включите 2FA.

**Перенос с VM (по желанию)**, вместо создания администратора:

```bash
sudo systemctl stop panel
sudo -u panel panel restore -data-dir /var/lib/panel multiprotocol-backup-….tar.gz
sudo -u panel panel set-host -data-dir /var/lib/panel <IP VPS>
sudo systemctl start panel
```

Порт и секретный путь будут как на VM: `sudo -u panel panel show-url -data-dir /var/lib/panel`. В «Домене» переключите адрес DuckDNS на «IP этого сервера (автоматически)» и перевыпустите сертификат.

## 4. Подключения, пока 443 занят 3x-ui

1. Создайте основное подключение VLESS + Reality + XHTTP на **другом порту** (мастер сам предложит свободный). Проверьте его с телефона.
2. Добавьте остальные протоколы (Hysteria2, TUIC и т. д.).
3. Маршрутизация: WARP, «Россия», гео-базы.
4. Домен: «Настройки → Домен и сертификат» (IP автоматически), затем сделайте домен публичным адресом.

## 5. Убрать 3x-ui и занять 443

Когда всё работает:

```bash
sudo systemctl disable --now x-ui
```

Не удаляйте 3x-ui сразу: если что-то пойдёт не так, `sudo systemctl enable --now x-ui` вернёт его. Затем поменяйте порт основного подключения на 443 и обновите подписки на устройствах (или просто откройте приложение: подписка обновится сама).

Удалить 3x-ui совсем можно через неделю спокойной работы: `x-ui uninstall`.

## 6. После переезда

- Обновления: «Настройки → Обновления → Обновить».
- Резервная копия: «Настройки → Резервная копия», храните файл в надёжном месте.
- Забыли пароль или потеряли 2FA: `echo 'новый-пароль' | sudo -u panel panel admin -data-dir /var/lib/panel -username ЛОГИН -disable-2fa`.
