# MultiProtocol

Open-source VPN-панель для личного использования. Xray, Hysteria2 и sing-box в одном спокойном интерфейсе, а рядом — управление клиентами штатной Amnezia, в согласии с её приложением. Без биллинга и реселлеров: панель для себя, семьи и друзей.

Технические имена (бинарь `panel`, сервис `panel.service`, Go-модуль `panel`) остались прежними. План и решения — в [PLAN.md](PLAN.md).

> Статус: работает на VPS (Ubuntu 22.04), релизы выходят часто. Вкладка «Серверы» (несколько VPS) — позже.

## Установка

Ubuntu 22.04+ или Debian 12+, x86-64 или ARM64, от root:

```bash
curl -fsSL https://raw.githubusercontent.com/CShark-root/multiprotocol/main/install.sh | sudo bash
```

Установщик скачивает последний релиз, сверяет контрольную сумму, ставит панель и ядра (Xray, Hysteria2, sing-box) и печатает адрес панели (`https://IP:ПОРТ/<секрет>/`) с отпечатком сертификата. Администратор создаётся при первом входе. Docker, контейнеры Amnezia и их правила iptables установщик не трогает.

Обновление — кнопкой «Настройки → Обновления». На экране видны шаги, таймер и журнал установки, а данные сохраняются. Можно и повторить команду установки.

Проверить сервер до установки, ничего не меняя:

```bash
curl -fsSL https://raw.githubusercontent.com/CShark-root/multiprotocol/main/scripts/vps-check.sh | sudo bash
```

Переезд с 3x-ui и других панелей: [docs/migration.md](docs/migration.md).

## Возможности

**Подключения**
- Xray: VLESS и Trojan с Reality (XHTTP, TCP/Vision, gRPC), VMess (WS, TCP), Shadowsocks-2022.
- Hysteria2: обфускация Salamander, port hopping (через свою таблицу nftables), сертификат домена или самоподписанный с закреплением.
- sing-box: TUIC, AnyTLS, ShadowTLS.
- Режим «Эксперт»: все параметры XHTTP и Reality (включая ML-DSA-65), sniffing, sockopt. Подбор сайта для маскировки Reality. «Тестовый набор» всех протоколов одной кнопкой.

**Пользователи и подписки**
- Лимит трафика, срок доступа, сброс по дням, неделям или месяцам. Продление в один клик, график трафика, кто сейчас онлайн.
- Две подписки: для приложений на Xray (Happ, v2RayTun, v2rayNG, Streisand) и на sing-box (Hiddify, NekoBox, sing-box). У каждого пользователя свой выбор подключений в подписке. Прямые ссылки и QR лежат в разделе «Дополнительно».
- Маршрутизация на устройстве для sing-box: всё через VPN, российское напрямую или через VPN только заблокированное.

**Маршрутизация на сервере**
- Гео-базы (в том числе runetfreedom) с автообновлением. Правила «напрямую / блок / WARP / свой выход».
- WARP регистрируется одной кнопкой. Сторож перезапускает Xray, если WARP перестал отвечать.
- Свои выходы по ссылке (vless, trojan, ss, vmess, socks, http). DNS по сайтам и экспертные флаги DNS.
- История изменений маршрутов с откатом.

**Amnezia**
- Контейнеры, установленные приложением Amnezia: состояние, нагрузка, логи, клиенты и их трафик. Версия AmneziaWG определяется так же, как в приложении (1.5 / 2 / 3.1).
- Клиентов AmneziaWG можно добавлять, переименовывать и удалять прямо из панели. Панель правит те же файлы, что и приложение, поэтому оба видят одних и тех же клиентов.
- Для каждого клиента два формата, как в приложении: ключ `vpn://` для AmneziaVPN и оригинальный `.conf` для AmneziaWG.
- Каждая правка осторожная: копия файлов в `/var/lib/panel-amnezia/backups`, отказ на незнакомом формате, проверка через `awg show` и откат при ошибке. Контейнеры не перезапускаются.

**Сервер и уведомления**
- Обзор: нагрузка, память, скорость сети, состояние ядер. Перезапуск ядер и перезагрузка VPS из панели.
- Домен с сертификатом Let's Encrypt (DuckDNS и другие).
- Telegram-бот:
  - уведомления о событиях;
  - зашифрованная резервная копия раз в сутки;
  - меню управления: сервер, пользователи (продлить, сбросить трафик, выключить, ссылка подписки), перезапуск, копия, перезагрузка.
- Журнал: живые логи панели и ядер, события, история действий администратора.

**Безопасность**
- Скрытая панель: случайный порт, секретный путь, только HTTPS. Чужие адреса получают пустой ответ или обрыв.
- Пароли на argon2id, ограничение попыток входа, двухфакторная аутентификация (TOTP). Сессия в cookie `HttpOnly; Secure; SameSite=Strict`.
- Панель работает от отдельного пользователя без root. Root-права есть только у трёх маленьких помощников со строго заданными запросами:
  - Docker для вкладки Amnezia;
  - nftables для port hopping;
  - обновление.
- Параметризованный SQL, строгий JSON, проверка Origin, строгий CSP.

Интерфейс на русском и английском, светлая и тёмная тема, работает и с телефона.

## Командная строка

```bash
panel show-url -data-dir /var/lib/panel            # адрес панели
panel set-host -data-dir /var/lib/panel HOST       # адрес для ссылок клиентов
panel admin -data-dir /var/lib/panel -username U   # новый пароль (со stdin), -disable-2fa
panel backup -data-dir /var/lib/panel -out FILE    # резервная копия
panel restore -data-dir /var/lib/panel FILE        # восстановление (панель остановить), в том числе .mpbk из Telegram
```

На сервере эти команды запускаются от пользователя панели: `sudo -u panel panel …`.

## Сборка

Нужны Go 1.27+ и Node.js 22+.

```bash
cd web && npm ci && npm run build && cd ..
go build -o bin/panel ./cmd/panel
```

На Windows: `scripts\build.ps1` собирает и версию для разработки, и Linux-бинарь для сервера. Релизы собирает GitHub Actions по тегу `vX.Y.Z`.

## Разработка

```bash
go run ./cmd/panel -dev -data-dir data-dev   # http://127.0.0.1:8080/dev/
cd web && npm run dev                        # http://localhost:5173/dev/ с hot reload
```

`-dev` слушает только `127.0.0.1` и работает без TLS. Тесты: `go test ./...`.

Проверка с настоящими ядрами, Amnezia и телефоном — на виртуалке: [docs/vm-setup.md](docs/vm-setup.md).
